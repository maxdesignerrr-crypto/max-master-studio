# კაფელ მეტლახის სასწავლო საიტსია

ეს პროექტი უკვე მოიცავს:

- 3 პროდუქტის არჩევა (ვიდეო, ვიდეო + პრაქტიკა, სტაჟირება)
- ყიდვის ღილაკი, რომელიც გახსნის მარტივ რეგისტრაციის ფორმას
- მომხმარებლის სახელი, გვარი, ტელეფონი და არჩეული პაკეტი
- ბანკის ანგარიშების ნახვა და კოპირების ფუნქცია
- Node.js backend, რომელიც შეინახავს შეკვეთებს `orders.json` ფაილში

## როგორ გამოვუშვათ ლოკალურად

### 1. დააინსტალეთ Node.js

- გადადით https://nodejs.org და გადმოწერეთ LTS ვერსია
- დააყენეთ თქვენს კომპიუტერში
- დააკონტროლეთ, რომ მუშაობს:

```bash
node -v
npm -v
```

### 2. გახსენით პროექტის ფოლდერი

`c:\Users\User\Desktop\AIProject`

### 3. დააინსტალეთ დამოკიდებულებები

```bash
npm install
```

### 4. გაუშვით სერვერი

```bash
npm start
```

### 5. გახსენით ბრაუზერში

```text
http://localhost:3000
```

### 6. ტესტის შემდეგ ნახვა

- შეკვეთები შენახული იქნება `orders.json`-ში
- საყიდლების სია შეგიძლიათ ნახოთ `http://localhost:3000/api/orders`

## რა უნდა იყოს `orders.json`-ში

პირველად `orders.json` უნდა შეიცავდეს ვერსას:

```json
[]
```

შემდეგ, როდესაც რაღაც ფორმა გაიგზავნება, იქ დაემატება შეკვეთები.

## თუ გინდა ეს საიტი სხვას გაუგზავნო

#### ვარიანტი A: დროებითი გაზიარება `ngrok`-ით

1. გადმოწერე და დააინსტალირე `ngrok`:
   https://ngrok.com
2. გაუშვი ტერმინალში:

```bash
ngrok http 3000
```

3. გამოიყოფა საჯარო URL, მაგალითად `https://abcd1234.ngrok.io`
4. მაგ URL-ს გაუგზავენი სხვას

#### ვარიანტი B: რეგულარული ჰოსტინგი

- გამოიყენე Render, Railway ან Vercel
- აირჩიე Node.js პროექტი
- Start command: `npm start`
- გადატვირთვის შემდეგ მიიღებ საჯარო URL-ს

## ფაილები

- `index.html` — მთავარი გვერდი
- `styles.css` — ვიჯეტების სტილი
- `script.js` — ვებფლოუს ლოგიკა და POST გამოძახება
- `server.js` — სერვერი `orders.json`-ის შენახვისთვის
- `package.json` — Node.js პროჯექტის კონფიგურაცია
- `orders.json` — შეკვეთების მონაცემთა ფაილი
